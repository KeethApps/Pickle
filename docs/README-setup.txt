1. Put this whole `docs` folder in the root of your repo.
2. Copy these from pickle-app-icon into docs/assets/ :
   favicon.ico favicon-32.png favicon-48.png apple-touch-icon-180.png pwa-192.png pwa-512.png
   (from the repo root:  cp pickle-app-icon/{favicon.ico,favicon-32.png,favicon-48.png,apple-touch-icon-180.png,pwa-192.png,pwa-512.png} docs/assets/ )
3. Replace keethapps/YOUR-REPO in docs/index.html with your GitHub repo path.
4. Push, then GitHub repo > Settings > Pages > Source: Deploy from a branch > main > /docs.
