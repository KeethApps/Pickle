# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Instead, use GitHub's [private vulnerability reporting](../../security/advisories/new) or email **getafterword@gmail.com** with:

- what you found and where
- steps to reproduce it
- the impact you think it has

I will acknowledge your report as soon as I can and keep you updated while it is fixed.

## Supported versions

Only the latest release receives security fixes.
