# Changelog

All notable changes to Pickle are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and Pickle uses [Semantic Versioning](https://semver.org/). While the version is below 1.0.0, minor releases (`0.x.0`) may include breaking changes.

Every entry goes under one of these headings: **Added**, **Changed**, **Deprecated**, **Removed**, **Fixed**, **Security**. Write for the people using Pickle, not for the people reading the code.

## [Unreleased]

### Added
- Inbox with swipe to sort, delete or remind
- 13 collections with their own cards, fields and filters
- Detail screens, including recipe ingredients with scalable servings and workout sets and reps
- Search and per-collection filters
- Reminders and tasks
- Tidy up for old saves
- Backup, JSON export and import, and Trash
- Landing page on GitHub Pages
